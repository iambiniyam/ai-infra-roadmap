# Code of Conduct

## Our pledge

We want this to be a place where people can be wrong out loud, ask basic questions, and get a real answer. That only works if everyone is treated with respect.

## Expected behavior

- Be direct about *ideas* and generous with *people*.
- Assume good faith. "This formula is wrong, here's the derivation" is welcome. "This is stupid" is not.
- If you correct someone, include the evidence.
- Respect that contributors are doing this for free.

## Unacceptable behavior

- Harassment, insults, or personal attacks of any kind.
- Discriminatory jokes or language.
- Publishing someone's private information without consent.
- Sustained disruption of discussions.
- Spam or undisclosed promotion of paid products.

## Scope

This applies to issues, pull requests, discussions, and any project space, plus public spaces when you're representing the project.

## Enforcement

Report problems to the maintainer ([@iambiniyam](https://github.com/iambiniyam)) via GitHub. Reports are handled confidentially. Responses range from a private warning to a permanent ban, depending on severity and pattern.
